# M08B 多商品经济与长期模拟设计

状态：核心经济、人口消费、存档迁移、长期模拟和模拟专用继承规则已于 2026-11-12 获用户批准并进入实现。

## 目标

按 `GDD_v4.0.md` §14.2 建立真实月结经济与长期模拟，使人口增长、商品供需、价格变动、产业停摆和家族存续可以由同一套规则产生。模拟必须驱动实际 `GameSession`，不可另写一套结果相似的经济模型。

## 已确认决策

- 用户选择真实价格与通胀规则，纳入游戏经济，不只生成统计用的价格序列。
- 在世家族成员产生月度消费需求。
- 使用多商品市场；第一版商品为粮食与生产物资。资金作为货币，情报不交易；暂不增加布匹等家用商品。
- 外部仓库没有比项目现有模式更合适的可直接复用市场模型。Scout 建议沿用现有 `IndustrySettlement`、月结事务、存档和测试运行方式，自建纯 C# 规则。

## 范围

- 为粮食和生产物资记录稳定 ID、库存、月供给、月需求、单位基准价和价格指数。
- 以家庭人口的实际需求和产业供需完成月度交易、消费和价格更新。
- 让价格影响家庭可负担消费及产业成本/运营结果；短缺可影响家族健康与长期灭族率。
- 将全部新状态接入当前月结原子回滚、存档验证和 v16→v17 迁移。
- 建立基于真实 `GameSession` 的 100 年、1000 种子模拟，导出 GDD §14.2 所有指标。
- 提供能读懂当前库存、两类价格、人口消费与短缺的游戏内说明；复用现有资源/产业界面，不另造第二套经济状态。

## 非目标

- 不加入多家族间的外交贸易、运输路线、地区差价、商人 AI、债务或贷款。
- 不把情报当作可购买的商品。
- 不引入第三方经济包、付费服务、外部资产或新 Unity package。
- 不用模拟器专用规则替代游戏规则，也不以批处理日期/私有字段注入作为 Play Mode 证据。
- 不宣称市场规则对应真实历史统计；概率和价格规则是可调的游戏模型。

## 方案比较

1. **统计型价格指数**：实现最简单，但价格不影响消费或产业，无法满足用户已选的真实经济规则，也无法让通胀对经济崩溃产生因果影响。拒绝。
2. **单一主粮市场**：可表达人口粮食压力，但不能分别观察家庭消费品价格与产业投入成本。用户选择多商品市场，因此不采用。
3. **粮食 + 生产物资的多商品市场**：为人口消费和产业投入分别记录供需及价格，并继续用资金结算。用户已选定此方案；新增领域状态，但商品范围仍限两类。

## 已批准规则（2026-11-12）

### 商品、库存与价格

- 商品稳定 ID：`market.food`（粮食）、`market.materials`（生产物资）。资金是唯一货币；情报不进入市场。
- `market.materials` 沿用现有 `IndustryResources.Supplies` 库存，不复制一份物资库存；粮食使用一个新库存。每种商品基准价格为 1 资金/单位，开局价格指数均为 1000‰。
- 月结先以月初库存加本月产业产出计算可用供给，以人口粮食需求加产业生产物资投入计算需求，再按稳定商品 ID 结算。月内账单使用上月结算出的价格；新价格在月末依供需更新，避免循环依赖。
- 价格更新式：`压力‰ = roundHalfUp((需求-可用供给)*1000/max(需求,可用供给,1))`；`变动‰ = clamp(压力‰/4, -100, +100)`；`新指数 = clamp(roundHalfUp(旧指数*(1000+变动‰)/1000), 100, 100000)`。等供需时价格不变；短缺涨价，过剩降价；单月最多涨/跌 10%。乘法使用 `long` 中间值，采用 half-up 舍入。
- 综合商品价格指数为粮食与生产物资固定 50/50 权重的基期篮子，即两项指数的 half-up 算术平均。极端通胀定义为综合指数相对 12 个月前增长至少 100%（价格翻倍）。这是游戏经济指数，不冒称真实历史 CPI。

### 家庭消费、支付与短缺

- 每月按月结开始时在世、属于当前家族的全部人物计算粮食需求，不只统计名册 UI 当前显示的六人。月需求为 `ceil(月初在世家族人数/5)` 单位粮食。
- 家族以当月冻结的粮食价格购买并消费；实际购买量为需求、可用库存、资金可负担量三者的最小值，月度总账单采用 half-up 舍入。资金与库存不得变为负数，不产生债务。
- 未满足粮食需求记录为连续短缺月数。每满 3 个连续短缺月，在下一个 M08A 年界为每位受影响者增加 50‰（5 个百分点）死亡概率，最多 +250‰（25 个百分点）；一个完整供足需求的月份将短缺月数归零。此修正不替换 M08A 年龄基准率，合计概率上限为 1000‰。
- 月结人口快照取月结起点；在该月结边界出生的人从下一月开始计入需求，年界死亡者仍计入本月需求。这与结算整月生活成本一致。若月结事务失败，人口消费、资金、库存、价格、短缺月数、日期、随机流和编年史全部回滚。

### 产业与物资流

- 保留当前产业任命与月结的纯规则边界；商品产出、投入及资金交易要以稳定产业 ID 的确定顺序结算。
- 月初人口快照取月结开始时；该边界月出生者从下月开始计入需求，月结后死亡者仍计入本月需求。这代表结算的完整月份。
- Farm 保留现有资金 +2、物资毛产出 4、物资 upkeep 1，并额外产粮 4 单位；Trading House 保留资金 upkeep 6、物资 upkeep 2、资金毛产出 9、情报 +1。现有固定输入/输出保持不变。
- 生产物资仍按现有产业投入扣库存；并按 `ceil(实际物资投入 * 物资基准价 * 物资指数 / 1000)` 增加资金成本，叠加在既有固定资金 upkeep 之外。Farm 自留物资同样计价；本月商品产出不另外产生浮动资金收入，避免重复计入既有固定收入。物资或资金不足时沿用现有 stalled 语义，不部分扣费或透支。
- 新游戏以 30 资金、12 生产物资及一个月人口粮食需求量开局。v16 迁移保留原资金、情报和产业状态，从旧物资库存拨出至多一个月粮食需求量作为粮食，其余仍为生产物资，因此不凭空增加存量。

### 人口、经济崩溃与模拟

- 饥荒死亡风险是 M08B 对已批准 M08A 自然死亡模型的明确扩展：保留既有年龄基准率，另加单独、可测试的粮食短缺修正；不得把两者混为同一概率或跳过原有检定顺序。
- 经济崩溃指标定义为“连续 12 个月未满足至少一个粮食单位需求，或所有已任命产业连续 12 个月停摆”的种子比例；无人任命产业不视为停摆。饥荒与产业停摆分别记录。
- 模拟按 20 个短期种子、200 个完整种子、1000 个完整种子分阶段运行；每个种子创建隔离的实际 `GameSession` 和 RNG 状态。事件用文档化、固定、可重放的选项策略处理。
- 每月事件由固定、文档化且可重放的策略选择有效选项并继续，直到不再有待决事件；只有 resolver 无法选择/完成且待决事件仍阻止推进时才记为死锁。模拟器使用现有 `GameSession` 继承 API 自动处理继承和摄政：优先有效指定继承人，否则按稳定 ID 选择最小的合法继承人；摄政按稳定 ID 选择最小的合法候选人。无合法继承人时保留现有停机分类。此策略不改变玩家实际继承规则；灭族单独记录，不丢弃该种子。
- 输出可机器读取的 CSV 与汇总 JSON，包含 GDD 指定的灭族率、继承人断档率、人口分布、平均年龄、财富分布、经济崩溃率、极端通胀、事件频率、关系异常和推进死锁。
- 财富定义为资金加按当前价格估值的粮食与生产物资，不含情报；1000 个独立种子各模拟一个家族，因此每个时间检查点以当时仍存活的种子所代表的家族作为财富分布样本，输出 P10/P25/P50/P75/P90。无存活家族的检查点单独计数，不插入零财富样本；这不代表同一世界中的跨家族分布。
- 先测单个 100 年种子运行时间，再扩大批量。现有月结会克隆继承和整段编年史，长测成本随历史增长；不先优化或限制真实游戏规则来制造更快的虚假结果。

### 存档与 UI

- 市场状态进入 v17 存档，包括每个商品的稳定 ID、库存、价格指数、上次结算月索引、家庭短缺连续月数及模拟指标所需最小累计数据。
- v16→v17 迁移保留资金、情报、人物/亲属、产业任命、编年史及所有既有任务状态；仅从旧物资库存拨出至多一个月粮食需求量作为新粮食，其余保留为生产物资。两项价格均以 1000‰ 初始化，短缺计数设为 0，不从旧存档臆造饥荒历史。
- UI 展示资金、粮食/生产物资库存、各自价格走势、当月人口消费/产业需求、未满足量和连续短缺月数；不展示模拟器内部实现细节。使用单一现有经济/产业页面入口。

## 已确认规则与审批状态

已确认：市场为多商品；商品首版为粮食与生产物资；资金作货币；情报不交易；家庭人口消费进入真实经济。

用户已批准以下设计进入实现计划：

1. 家庭粮食需求按“每 5 人每月 1 单位，向上取整”，以当月价格购买；库存或资金不足时不负债并记录短缺。
2. 每满 3 个连续短缺月，年度死亡概率增加 50‰，最多 +250‰；一个月完全供足需求即重置连续短缺数。
3. 两商品指数范围 100..100000‰，每月变化 ±100‰；50/50 综合指数同比翻倍为极端通胀；供需公式与舍入规则见上。
4. Farm 额外产粮 4 单位，其余现有产业固定输入/输出不变；生产物资价格增加投入成本。
5. 新游戏粮食库存为一个月需求量；v16 迁移从原物资库存中拨出至多一个月需求量，总存量不增加。
6. 经济崩溃采用连续 12 个月粮食短缺/所有已任命产业停摆；财富分位数按 10/25/50/100 年仍存活的独立种子统计，即每个种子中的单个家族。GDD 未设平衡目标，先用 20/200 种子结果调参，不编造通过阈值。

边界探针：价格指数 100..100000‰、单月变化 ±100‰，库存/资金下限 0；供需分母为 0 时取 1；按 `market.food`、`market.materials` 稳定顺序结算；0 人需求为 0、1..5 人需求为 1，同月出生/死亡不改变月初快照；重复月结拒绝且整体回滚；迁移和模拟导出覆盖无效及失败数据。事件须由固定 resolver 持续处理；仅处理失败并阻断日历推进时计作死锁。财富样本为独立种子所代表的单个家族，不能误称同一世界跨家族财富分布。

禁止事项：不得使资金或库存变负、不得把物价序列与实际库存/交易脱节、不得悄悄改变 M02/M03 的产业语义、不得丢弃停机种子、不得把 GDD 指标换成更容易通过的替代指标、不得以价格指数增长替代真实死亡/停摆记录。
