# M00 演示试玩与用户验收步骤

## 验收目标

检查 Windows 演示的标题、新局、月结、地图、清洲城镇及当地委托页面能否按顺序打开，并确认日期与资金变化正确。路线不要求接取委托或存档。

## 用户试玩步骤

启动本机演示程序：

Builds/ShadowClan-v1-demo-win64-2bca9d1-r2/ShadowClan-v1-demo-win64-2bca9d1-r2.exe

1. 在标题页点击「开始新游戏」，再选「固定三代剧本（SC-013）」。
   - 预期：进入 SC-013 新局，不进入继续游戏或读档流程。
2. 查看初始营地 HUD。
   - 预期：日期 1560-04-01，地点「清洲」，家族登记 6 人，资金 30，物资 12。
3. 点击左侧「地图与出行」进入地图页，再点击「结束月份」。
   - 预期：月结完成，日期显示 1560-05-01，资金变为 28，物资仍为 12。
   - 如果出现事件选择，选择「守住对伊织的承诺」后继续。
   - 事件预期：反馈说明伊织对家族的信任增加五点。
4. 在地图点击当前位置「清洲」。
   - 预期：打开清洲城镇页；可看到「尾张旧都 · 城郭与城门之间的街町」及当地人物。
5. 查看城镇页的「当地委托」区并点击「护送委托」。
   - 预期：当地活动列表包括补给短缺、密信、护送委托、潜入密令；护送委托页显示「待接取（清洲本家）」、3 个模拟日、接取投入 4 资金、结局奖励及风险说明、执行人入口。

## 通过条件

以上各页均能打开；显示日期、资金和物资与预期一致；当地委托列表非空；护送委托详情完整可读。若有页面打不开、数值不符或列表为空，停止并记录页面文字与当时日期。无需接取委托，不要执行存档/读档。
