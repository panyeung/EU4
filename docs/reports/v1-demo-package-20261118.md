## 一到两分钟试玩路线

1. 启动程序，确认显示标题页。
2. 选择「开始新游戏」，再选固定三代剧本 SC-013。
3. 在营地确认日期为 1560-04-01、地点为清洲、资金为 30。
4. 选择「结束月份」，确认推进到 1560-05-01，资金变为 28。
5. 打开地图，进入清洲城镇页，确认当地委托列表可见，再打开委托页。

依次确认标题页、三代剧本、营地 HUD、月结和城镇委托页都能打开。此路线不操作存读档菜单。

若页面无法打开、日期或资金不符、委托列表为空，停止试玩并记录画面文字。不要继续推进月份。构建卡记录这条路线结束时 `Player.log` 没有 Exception、LogError 或 NullReference。
