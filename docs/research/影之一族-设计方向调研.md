## 0. 先纠正任务前提

任务卡写的是「在不知道具体形态的情况下」。这个前提不成立，本仓库已经给出了形态：

- `checkpoint.md` 1.1：玩家扮演战国忍者家族的当代家主，主角是家族不是某个人物。四大支柱为家族经营、角色扮演、家族传承、忍者战术。
- 1.6 已批准且已实现：名望 `0..100`、隐蔽度 `0..100`（新档 50）、每名雇主独立信用、势力关系 `-100..100`。名望与隐蔽度**独立，不互为反值**。
- 1.8 已实现：八类忍者任务、五档统一结果、M06 战术场景（3→5 人、每人每回合 2 AP、忍术含烟雾/幻惑/陷阱/支援）。
- 1.9：1560 年开局，史实压力点为 1579/1581 天正伊贺之乱、1600 关原、1614–1615 大阪之阵。
- 3.2：继承（`SuccessionService`）、编年史（`HistoryLedger`）、事件系统（允许列表条件与效果）、产业市场均有代码与测试。

所以「最可能的两种形态」在本项目里不是二选一，而是主从关系：

| 形态 | 在本项目中的位置 | 处理方式 |
|---|---|---|
| 玩法阵营 | **主**。玩家本身就是「影之一族」，不需要再「选择阵营」 | 本文第三部分的方向设计针对它 |
| 叙事世界观派系 | **从**。一族是 1560 年势力网里的一个节点 | 本文第二部分末给出可直接复用的史实派系骨架 |

任务卡举的三个例子中，「隐匿刺客型」在技术上已经是现状（四维 + 八类任务 + 五档结果 + 战术场景），再立为一个「方向」只是重复。本文改为在它之上分层。

## 2. 史实层：先划清哪些能用、哪些是创作

这一层比案例更重要，因为它直接决定哪些方向与项目的「史实模式」自洽。

### 2.1 可用作机制的真实素材

| 史实结论 | 依据 | 可转化成的机制 |
|---|---|---|
| 忍び的第一职务是受命收集情报；被要求活着回来报告，因此尽量避免战斗 | 三重大学忍者研究中心页面原文 | 任务类型中情报类权重应高于暗杀类；暗杀失败的成本应显著高于情报失败 |
| 现存忍术传书（《万川集海》《正忍記》）里几乎没有暗杀术条目，核心是侵入、变装、交际、记忆、传达、火术、医药、气象 | 山田雄司相关论文（转述，正文未直连） | 忍术技能树应以「侵入 / 变装 / 火术 / 医药 / 传达」为骨架，而不是「暗杀技」 |
| 陽忍＝公开露面、以计略与变装行事；陰忍＝隐匿身形潜入。这是《万川集海》的**术法分类**，共 陽忍 3 卷、陰忍 5 卷 | 《万川集海》维基卷目表（已直连核对） | 可以直接做成玩家侧的两套行动模式，且不需要任何超自然解释 |
| 変装的七种外面身份（七方出）：虚无僧、出家、山伏、商人、放下师、猿乐师、常之形（平常装扮） | 国立国会图书馆页面原文确认出自《正忍記》 | 现成的「表向身份」清单，可直接做成一族可经营的伪装产业 |
| 伊贺：地侍・土豪以「伊賀惣国一揆」联合自治。掟书规定外敌入侵则「惣国一味同心」、各村鸣钟集结、17–50 岁有出阵义务、忠节百姓可被提拔为侍、通敌者讨伐 | 伊贺惣国一揆维基与三重大学讲义 | 可做成一族被入侵时的真实动员规则（鸣钟动员、年龄义务、阶级晋升通道） |
| 甲贺：以同姓同族「同名中」为基础形成郡规模的「甲賀郡中惣」，合议制、多数决、决不出时抽签 | 甲賀郡中惣维基 | 与伊贺的「惣国一揆」是两种不同的 AI 家族决策模板：一个是全民动员，一个是名门合议 |
| 伊贺与甲贺是「甲伊一国」式的紧密邻接社会，有婚姻与入会地协定，**不是世仇** | 甲賀流维基、产经新闻 | 若剧本写成两地世仇，属于创作而非史实 |
| 天正伊贺之乱：1579 年织田信雄擅自出兵约 1 万被击退；1581 年六方向同时攻入，约半月平定 | 战国相关站点与维基 | 与本项目 1.9 的历史节点一致，可放心使用 |
| 乱后伊贺经筒井定次到藤堂高虎；甲贺武士浪人化，1667 年起向幕府提出「甲賀五十三家」等由绪申诉以求恢复武士身份 | 同上 | 「一族被解除武装后靠文书申诉恢复身份」是可用的跨代事件链母题 |

### 2.2 必须标为虚构、不要写成史实的部分

| 常见说法 | 判定 | 依据 |
|---|---|---|
| 「影」被用作忍者组织名 | **无史料依据** | 可考称谓是 忍び、乱波、透波、草、かまり、伊賀者、甲賀者、伊賀同心、御忍之衆、早道之者。「影」作为忍者集团名最著名的用例是 1980 年电视剧《服部半蔵 影の軍団》 |
| 上忍 / 中忍 / 下忍 是身份階级 | **误读** | 《万川集海》所说上忍是「不为人知而精于术者」，是能力评价，不是身份制度；三段階级属后世整理 |
| 风魔小太郎是历史人物，与服部半藏为宿敌 | **1920–30 年代建构** | 同时代史料无法确认此人。素材来自《北条五代记》的乱波「风魔」、《鎌倉管領九代記》的「風間小太郎」、《见闻集》的盗贼逸话，经三田村鳶魚、白石实三合并塑造；「风魔手里剑」「杀半藏」纯属虚构 |
| 服部半藏是伊贺忍者头领 | **不准确** | 服部正成是德川谱代家臣、旗本先手武将、德川十六神将之一；「半藏」是代代袭名通称。半藏门之名确实来自父子通称 |
| 「伊贺 9 千对织田 4–5 万、死者 3 万」「伊贺十二人众」名单 | **史料可信度低** | 出自江户期军记《伊乱记》（1679），近年研究倾向排除无一次史料佐证的记述 |
| 「全村皆忍者、各有表里两职」的制度性双重身份 | **设定而非史实** | 伊贺众本质是地侍，从事忍び働き是必要时的军事劳务之一。真正有史实对应的是江户期伊贺者/甲贺者「平时为下级武士警备、偶尔受命秘密侦察」，以及陽忍的变装术 |

**对本项目的直接含义：** 标题「影之一族」是创作设定，不是史料概念，这没有问题，但剧本与编年史文本不应把它表述为史实称谓。而「陰/陽」这一对词是真实存在的忍术分类，用它命名一族的两套行动模式，比用「影」更立得住。

## 3. 同类作品的阵营设计范式

八个案例（L5R 蝎族、MTG House Dimir、Dishonored 捕鲸人、Thief 守护者、Shogun 2 忍者/目付、Sekiro 枭、Warhammer 暗影战士、Mortal Kombat Lin Kuei）收敛出七条可迁移规律。

1. **阶层＝信息权限，不是战力加成。** Dimir 是公开层/隐秘层/深层三级（深层连成员都不知道）；蝎族四个家系按「欺骗的类型」分工；守护者是 First Keeper→Elder→Scribe→Acolyte 的阶梯。升阶的意义是「能知道更多」。
2. **隐蔽是反向资源，必须能被消耗和恢复。** Shogun 2 的忍者默认隐形、失败即自我暴露、只能被同类或目付发现；Dimir 一旦曝光就被迫长出公开面孔，真正力量退回二线。
3. **名誉当货币，可双向花费。** 蝎族是唯一做成数值的：起始 honor 更低（据 FFG 设计文章），dishonor 对手是主武器，自我 dishonor 是主代价，honor 归零即败。
4. **超自然能力由首领「分配」而非个人修炼。** Daud 的 Arcane Bond 把弱化版能力授予部下；龙胤只有一条血脉。副作用是「刺杀首领＝系统级胜负」，这天然限制了势力无限膨胀。
5. **反制必须成三角，且各角由不同资源供给。** Shogun 2 是 忍者↔目付↔僧侣，三者由酒屋/市场/寺庙三条不同建筑链产出，所以「你选了哪个阵营」等于「你在情报生态里占哪一角」。
6. **基础设施型能力比数值加成好玩，但必须留总开关。** 守护者的 Door Glyph 是全城后门网，配套设计 Final Glyph 一次性抹除全部。
7. **影之阵营的收入来源本身就是曝光源。** 几乎所有案例都把「政治孤立」写进代价：暗影战士无盟友无补给、捕鲸人被当外包工具、Lin Kuei 接单即树敌。不能既拿高报酬又保持干净。

两条横向警告：多个案例的首领一离开组织立刻碎裂（Daud 走后捕鲸人分裂互斗、Owl 背叛苇名、Sektor 篡位），说明这类阵营的稳定度应当显式低于武士政权，**用继承危机而不是数值削弱来平衡它**。

## 4. 血脉与世代传承的机制范式

七个案例（CK3、Massive Chalice、Wildermyth、FE4 圣战谱系、《太吾绘卷》、《太阁立志传V》忍者里、Battle Brothers）给出三种「血脉载体」，可叠加而非互斥。

| 载体 | 代表 | 继承什么 | 代价设计 |
|---|---|---|---|
| 生理基因 | CK3、Massive Chalice、FE4 | 可遗传特质、成长率、血统专属武器 | 近亲缺陷 / Regent 永久退出战场 / substitute 更弱 |
| 身份器物 | 《太吾绘卷》伏虞剑柄 | 历代积累的造诣与功法 | 继任者原有武功清零、威望与人际关系不转移 |
| 故事名号 | Wildermyth | 技能、变形、传说级身份 | 家谱与婚姻记忆全部丢失 |

共性四条：

1. **可玩的血脉必须带代价**，否则退化成单一路径。CK3 社区最集中的批评就是「育种是唯一最优解」，有人装 mod 直接禁用 Blood 传承。
2. **传承必须被看见**：CK3 五星传承树、Wildermyth 星级名册、FE4 圣血图表、太吾遗惠列表，都是把不可逆的时间做成可读的进度。
3. **最常见的失败模式是「后期绕过」**：Massive Chalice 后三分之一可直接招募接近满级英雄，削弱了失去关键英雄的痛感。
4. **节奏惩罚比数值失衡更伤**：Wildermyth 的「和平年」因清图快而加速老化，被社区明确指为叙事与机制互相打脸。

反面参照 Battle Brothers：完全不做传承，队伍取代个人，战术自由但玩家与个体之间的情感被稀释。RPS 的评语是「没有 legacy，没有可继承的子女，只有队伍」。

## 5. 三个可选设计方向

### 方向一「陰陽双面」——一族两副面孔

**核心卖点。** 白天是由「七方出」里挑一门正经生意做的商家/艺能/医家，夜里是受雇的忍び。玩家每代真正要回答的问题不是「打得多好」，而是**这一代要露多少脸**。

**机制要点。**

- 家名分两层：表向（公开家业，从七方出择一：商人、猿乐师、山伏、医家……）与裏向（忍び众）。表向等级供给雇主信用与委托渠道，裏向等级供给潜入与情报能力。
- 隐蔽度（已存在，0..100）成为穿透表里的唯一阀门：表向经营抬升名望，同时消耗隐蔽度；隐蔽度跌破阈值后，敌方才能锁定你的据点。这正对应 Shogun 2「默认隐形、失败即现身」的可计算规则。
- 族内阶层用信息权限而非战力来切分：入门只知道据点；中级知道雇主的真名；上级知道这一族真正的委托链（Dimir 三级 + 守护者阶梯的合体）。
- 反制三角史实化：忍び ↔ 目付/同心 ↔ 山伏・僧。山伏本就是七方出之一，天然自洽。
- 势力层可直接复用两种史实自治形态：伊贺式「惣国一揆」（鸣钟动员、17–50 岁出阵义务、忠节百姓可升为侍）与甲贺式「郡中惣」（合议、多数决、僵局抽签），作为两类 AI 忍者众的行为模板。

**实现成本：低—中。** 名望/隐蔽度/雇主信用已实现且有测试；事件系统的允许列表条件与效果足够承载表里身份的事件链；继承服务已存在。主要新增是「表向身份」这一维度及其 UI 表达，不需要新存档大改（`[推断]`，依据 3.2 已实现边界）。

**风险。** 名望与隐蔽度已在 1.6 被批准为**独立、不互为反值**。表里设计很容易顺手把它们做成反值，那会推翻已批准决策。必须坚持两者独立，用「表向行动消耗隐蔽度」来表达张力，而不是把两者接成一条轴。另外需要一套能同时显示表里两套身份的 UI，否则玩家感知不到这条设计。

---

### 方向二「影之秘术」——超自然授权型

**核心卖点。** 「影」是一族世代看守、可分配、可被窃取的东西（Daud 的 Arcane Bond + 龙胤只有一条）。家主把影授予谁，谁就获得非常规能力。

**机制要点。**

- 忍术从四维检定升级为有资源池与冷却的技能，且**由家主分配**给指定族人与家臣，而非各自修炼。由此得到天然平衡阀：刺杀家主＝系统级胜负。
- 必须有反制器：对应 Dishonored 里 Abbey 的音乐盒可整体压制 Outsider 授予的能力。没有反制器的话，秘术强度会直接等于一切。
- 秘术有代价（龙胤的复活伴随龙咳式扩散），否则一族无敌。

**实现成本：高。** 需要新资源体系、新技能状态、战术场景内视效，以及新美术资产。直接撞 1.15 范围红线「暂缓大量忍术动画」。

**风险。** 与 1.9 的史实模式与 1600 关原 / 1615 大阪之阵等真实节点在调性上冲突；`ui设计规划.md` 的色板是深靛 + 古金 + 羊皮纸 + 朱印，没有为超自然影色留位置，需要新增色板项与一整套资产。最容易演变成「秘术强弱决定一切」，破坏设计红线 5「允许多种发展方式」。

---

### 方向三「被放逐的古血」——血脉型

**核心卖点。** 一族的血里有别人不认的东西：被放逐、被诅咒、或被神授。它把「家族传承」支柱从叙事层压到数值层，是四大支柱里目前机制化程度最低的一个。

**机制要点。**

- 三层并行（调研结论里最稳的组合）：家系层＝可遗传特质；器物层＝家宝与忍术秘卷承担跨代传递（太吾剑柄式，继任者需重修但可继承部分造诣）；家名层＝用名望解锁传承树，以雇主信用为解锁门槛（CK3 Legacy 式，但把外交资源绑进去）。
- 可遗传特质与隐蔽度挂钩：血脉越显赫越容易被认出，把已有数值变成遗传的代价（`[推断]`）。
- 必须带代价：近亲育种累积缺陷；继任者原有能力清零。

**实现成本：中—高。** `SuccessionService` 已存在可挂接，但遗传特质、隐性携带概率、家族树可视化都需要新存档字段与 UI。SC-017 家谱图目前严格只读。

**风险。** 三个已被验证的失败模式：CK3 的「育种成为唯一最优解」、Massive Chalice 的「后期可直接买满级英雄绕过」、FE4 的「用叙事惩罚机制失误（substitute 更弱）」。设计红线 5「允许多种发展方式，不强迫军事征服」在血脉最优解面前会很脆弱。另有一个价值观层面的不适感：《Massive Chalice》评论里「以牲畜交易商的利落眼光打量英雄」就是这条路走极端的必然代价。

## 6. 方向对比表

| 维度 | 方向一 陰陽双面 | 方向二 影之秘术 | 方向三 被放逐的古血 |
|---|---|---|---|
| 一行概括 | 一族两副面孔，靠表里切换做生意 | 影是可分配的超自然授权 | 血脉是可遗传、可经营的家产 |
| 核心张力 | 这一代露多少脸 | 把影交给谁 | 娶谁、谁来承继 |
| 主要服务的支柱 | 家族经营 + 忍者战术 | 忍者战术 | 家族传承 |
| 史实自洽度 | 高（陽忍/陰忍、七方出、惣国一揆均属实） | 低 | 中（需标为创作） |
| 复用现有系统 | 名望/隐蔽度/雇主信用/事件/继承 | 四维 + 战术场景（需大改） | 继承服务（需扩展） |
| 实现成本 | 低—中 | 高 | 中—高 |
| 主要风险 | 与已批准「名望隐蔽度独立」冲突 | 撞 1.15 红线；调性与色板冲突 | 育种最优解；后期绕过 |
| 玩家可感知度 | 中（需要新 UI 表达） | 高 | 高 |

## 7. 取舍标准：三个问题，一句话选定

1. 你想要的一族，是**一群在暗处做正经生意的人**（方向一），还是**身上有东西不对劲的血脉**（方向三），还是**掌管超自然之影的术者集团**（方向二）？
2. 你希望这一代人反复权衡的是**露多少脸**（一）、**娶谁**（三），还是**把影交给谁**（二）？
3. 你愿意付多少实现成本：低—中（一）、中—高（三）、高（二）？

选定只需回一个字：`一` / `二` / `三`。若要组合，唯一稳妥的组合是一 + 三：一是玩法底，三是第二世代往上叠的系统。

---

## 8. 一句式推荐

**选方向一**：把「影」定位成一族表里两副面孔的生意逻辑（陽忍做表象、陰忍做实质），因为它几乎不新增系统就能吃满四大支柱，且是三个方向里唯一能被史料站住的；方向三留作第二代血脉扩展。

附带两条不做的事。第一，不要把「影」写成超自然秘术，那与 1.9 的史实模式和现有色板都不合。第二，「隐匿刺客型」不需要再立项，项目已经是它了。
